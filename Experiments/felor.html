FELOR

Felor is a mobile application built to enable remote control of household electrical devices through microcontroller hardware integrated into manual switchboards. I self-learned Flutter and Dart to develop the mobile interface and connect it with embedded hardware for real-time device control.

The backend uses Firebase for secure storage and reliable app-to-device communication. The system was designed for scale, targeting up to 80% of typical households and supporting control of up to four switches and three fans per room.

What I Built

Key implementation points and technical focus.

  • Self-taught Flutter and Dart, integrating microcontroller hardware in manual switch boards for remote control.
  • Leveraged Firebase, MySQL, and Google Cloud for robust backend and secure data storage.
  • Designed to target 80% of households, achieving remote control of up to 4 switches and 3 fans per room.

Outcome

The experiment proved a practical path from prototype to real household deployment.

Cross-stack delivery from mobile app interface to physical switch-board integration.
Reliable remote control flows backed by cloud-connected storage and sync.
Feasibility validated for mainstream home usage constraints.
Strong foundation for scaling automation scenarios room-by-room.
