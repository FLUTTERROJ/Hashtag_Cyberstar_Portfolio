Shadow Taxi

A safety-first transport concept focused on transparent routing, dispatch visibility, and reliable rider updates.

Secure dispatch. Clear trip visibility.

Problem & Context

Night transport can feel uncertain without trusted visibility.

Riders often lack confidence in late-night travel because status updates are inconsistent and handoffs are opaque.

The project focused on reducing that uncertainty through clear trip states and better operator coordination.

Design constraints included low-friction reporting, simple state transitions, and clean interfaces under stress.

The core challenge was balancing operational detail with a calm, fast user experience.

Solution Overview

Core workflow and value delivered.

Unified trip-state timeline visible to riders and operators.
Operator console for assignment and exception handling.
Simple escalation model for delayed or abandoned routes.
Location-aware updates with explicit arrival confidence.
Clear handoff between dispatch, driver, and support teams.
Operational logs for post-trip review and learning loops.

Architecture

Service boundaries built for dependable operations.

Next.js FastAPI Postgres Redis
  • Typed APIs between rider app and dispatch tools.
  • Event-style logging for auditability and incident review.
  • Data model optimized around trip lifecycle states.

Engineering Decisions

Tradeoffs and implementation choices.

Realtime state updates via polling first, websockets later
Centralized trip-state enum to prevent UI drift
Lightweight operator dashboard before full admin suite
Prioritized reliability over edge feature density
