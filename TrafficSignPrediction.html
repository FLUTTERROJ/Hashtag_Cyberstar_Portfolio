Traffic Sign Prediction

The project focuses on building a traffic sign classification system using a subset of the German Traffic Sign Recognition Benchmark (GTSRB) dataset. The dataset contains images of 43 different traffic signs, including regulatory signs (e.g., speed limits), warning signs (e.g., curves, slippery roads), and mandatory instruction signs (e.g., turn left, go straight).

The goal of the project is to accurately classify these signs under real-world conditions, including variations in lighting, angles, and partial occlusions. The project pipeline involves feature extraction, preprocessing, model training, and evaluation, with the final step being an ensemble classifier that combines Decision Tree, SVM, and Linear Regression models, using a Decision Tree as the meta-model for aggregation.

Fast sign classification for safer autonomous perception.

Problem & Context

Why it mattered and constraints that shape the build.

Traffic sign recognition is a key task for autonomous driving and advanced driver-assistance systems (ADAS). Vehicles must correctly interpret signs to navigate safely, but real-world conditions like changing lighting, camera angles, occlusions, and busy backgrounds make classification challenging.

This project uses a subset of the German Traffic Sign Recognition Benchmark (GTSRB) dataset, which includes 43 classes of signs, such as regulatory, warning, and mandatory instruction signs. The dataset is split into a labeled training set and an unlabeled test set for evaluation.

In addition to images, pre-extracted features are provided, including color histograms, HOG descriptors reduced via PCA, and features like edge density, texture variance, and average color channels. The project also involved engineering additional features and applying preprocessing to improve model performance.

Models implemented include Decision Tree, Support Vector Machine (SVM), and Linear Regression, combined into an ensemble model using a Decision Tree as the meta-classifier. The project included training and evaluation on the labeled data, followed by predicting labels for the test set, providing a complete pipeline for robust traffic sign classification.

Failures & Challenges

What did not work first and what changed.

Pre-extracted features were sometimes insufficient, requiring additional feature engineering.

Individual models (Decision Tree, SVM, Linear Regression) had inconsistent accuracy across classes.

Some traffic sign classes had very few samples, causing higher error rates for minority classes.

Finding optimal settings for multiple models and the ensemble required iterative experimentation.
